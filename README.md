# Génération-de-CV :

*Dans le cadre d'un projet étudiant, j'ai réalisé un générateur de CV ayant pour challenge de passer les ATS (I.A qui vérifie la pertinance d'un CV).*

## Langage utilisé :

- **Java-Script**
- **PHP version 8.4 -> HTML**
- **Bootstrap 5.2.3**
- **Dompdf**

## Utilisation : 

L'objectif finale et d'arrivé à générer une double page. Ou l'utilisateur pourra voir en direct les modifications apporté à son CV avec un modèle prédéfinit. Une fois toutes les informations complété, possibilité de généré le CV sous format PDF.
